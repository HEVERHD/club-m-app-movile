Patrones de Diseno

Zustand Store Pattern

Estado global con acciones encapsuladas y persistencia opcional.

const useStore = create(persist(
  (set, get) => ({
    data: [],
    setData: (data) => set({ data }),
  }),
  { name: 'store-key' }
));

React Query Pattern

Queries con cache automatico y refetch inteligente.

const { data, isLoading } = useQuery({
  queryKey: ['clubs', tenantId],
  queryFn: () => fetchClubs(tenantId),
  staleTime: 5 * 60 * 1000,
});

Custom Hook Pattern

Logica reutilizable encapsulada en hooks personalizados.

export function useBiometrics() {
  const [isAvailable, setAvailable] = useState(false);
  const authenticate = async () => { ... };
  return { isAvailable, authenticate };
}

File-based Routing

Rutas definidas por estructura de carpetas (Expo Router).

app/
├── (auth)/login.tsx → /login
├── (tabs)/home.tsx → /home
├── club/[id].tsx → /club/:id
└── coupons.tsx → /coupons

Theme Context

Tematizacion global con React Context y hooks.

const { colors, isDark, setTheme } = useTheme();

<View style={{
  backgroundColor: colors.bg.primary
}} />

API Service Pattern

Servicios API centralizados con interceptores Axios.

// api/clubs.api.ts
export const getClubs = async (tenantId: number) => {
  const { data } = await client.get('/clubs', {
    params: { tenantId }
  });
  return data;
};
